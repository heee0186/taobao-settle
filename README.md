# 타오바오 정산

타오바오 주문 페이지를 붙여넣으면 날짜별로 정리하고, 카드 청구액으로 실제 환율을 역산해서 사람별 지출을 나눠 주는 개인 페이지.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html`, `style.css`, `app.js` | 페이지 본체 |
| `config.js` | 수파베이스 주소와 키 |
| `api/translate.js` | 상품명 번역용 버셀 서버 함수 (DeepL) |
| `supabase.sql` | 수파베이스 테이블 만드는 SQL |

## 설정 순서

### 1. 수파베이스
`tb_docs` 테이블은 프로젝트 2(예절퀘스트와 같은 곳)의 `money` 스키마에 있고, 가계부 저장소의 `supabase/migration/1-setup-money-schema.sql`로 만들어요.
`config.js`에는 그 프로젝트의 `Project URL`과 **Publishable key**(`sb_publishable_…`)를 넣어요.

### 2. DeepL 무료 키 받기
1. DeepL 사이트에서 **DeepL API Free**에 가입한다. 일반 DeepL Pro 구독이 아니라 개발자용 API Free다.
2. 계정의 API Keys 메뉴에서 키를 복사한다. 무료 키는 끝이 `:fx`로 끝난다.

### 3. 깃허브에 올리고 버셀 연결
1. 이 폴더를 새 깃허브 저장소에 올린다.
2. 버셀에서 **Add New → Project**를 누르고 그 저장소를 Import한다. Framework Preset은 **Other**로 두고, 빌드 설정은 건드리지 않는다.
3. **Settings → Environment Variables**에서 다음을 추가한다.
   - Name: `DEEPL_API_KEY`
   - Value: 2번에서 받은 키
4. 환경변수는 추가한 뒤의 배포부터 적용된다. **Deployments**에서 최신 배포를 **Redeploy**한다.

## 쓰는 법
- 번역은 날짜 화면의 **한국어로 번역** 버튼으로 한다. 한 번 번역한 상품은 저장돼서 다시 번역하지 않는다.
- 번역 결과가 마음에 안 들면 상품명 옆 **수정**을 눌러 직접 고친다.
- 번역 전에 包邮, 新款, 【…】 같은 광고 문구는 자동으로 걷어낸다. 걸러낼 단어를 더 넣고 싶으면 `app.js`의 `cleanTitle`을 고친다.
- 품목마다 구매자 선택 버튼이 있다. 지정하지 않은 품목은 **기본** 구매자로 계산되니, 다른 사람 몫만 바꾸면 된다.
- 사람 추가, 이름 수정, 삭제, 기본 변경은 사람별 지출의 **사람 관리**에서 한다. 사람을 지우면 그 사람 몫이던 품목은 기본 구매자로 돌아간다.

## 알아둘 점
- 주인 계정으로 로그인해야 수파베이스 자료를 읽고 쓸 수 있다. 공개 키가 코드에 있어도 권한 정책이 막는다. 검색엔진에는 안 뜨도록 `noindex`를 넣어 뒀다.
- DeepL 무료는 월 50만 자까지다. 다 쓰면 결제되는 게 아니라 다음 갱신일까지 번역만 막힌다.
- 수파베이스 무료 프로젝트는 오래 안 쓰면 일시정지될 수 있다. 그때는 대시보드에서 다시 켜면 된다.
- `app.js`를 바꾼 뒤 깃허브에 푸시하면 버셀이 알아서 다시 배포한다.

## 배송 현황
- `bookmarklet.html`을 열어 **타오바오 물류** 버튼을 즐겨찾기 바에 끌어다 놓는다 (처음 한 번).
- PC 브라우저에서 타오바오 已买到的宝贝 화면(待收货 탭 추천)을 열고 버튼을 누르면, 화면의 모든 주문 물류 기록을 모아 복사해 준다.
- 정산 사이트 입력칸에 붙여넣으면 **배송 현황**에서 `중국 배송 → 창고 → 국제 운송 → 한국 통관 → 국내 배송 → 받음` 단계로 보인다. 같은 시각에 창고에서 출고된 주문은 한 소포로 묶인다.
- 국내 운송장 번호는 타오바오에 나오지 않아서, 문자로 받은 번호를 넣으면 네이버 배송조회 링크가 생긴다.
- 웨일 확장 프로그램(`extension/`)을 설치하면 3시간마다 자동으로 확인해서 저장한다. 설치 방법은 `extension/README.md`.

## 통관 상세 (관세청 유니패스)
- 배송 현황의 소포가 **국제 운송** 단계가 되면 `운송장 번호 (유니패스의 House B/L)` 칸이 생긴다. 유니패스에서 확인한 H B/L 번호를 한 번 넣으면, 그 뒤로는 배송 현황을 열 때마다(30분 간격) 관세청에 자동으로 조회해서 입항·반입·심사·반출 단계를 보여준다. 반출이 끝나면 더 조회하지 않는다.
- 필요한 것: 버셀 환경변수 `UNIPASS_API_KEY` (Production·Preview 체크 후 Redeploy).
- 키 받는 법: 유니패스(unipass.customs.go.kr)에 로그인 → OPEN API 메뉴(사이트맵에서 찾을 수 있음) → 사용 신청에서 **화물통관진행정보 조회**를 신청 → 승인되면 OPEN API 메뉴의 인증키 조회에서 키를 복사한다. 메뉴 이름은 조금 다를 수 있다.
