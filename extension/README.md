# 타오바오 배송 자동 확인 (웨일 확장 프로그램)

웨일이 켜져 있는 동안 정해진 간격(기본 3시간)마다 아직 안 받은 타오바오 주문의 배송 기록을 확인해서 정산 사이트에 저장해요.

## 설치 (처음 한 번)
1. 이 `extension` 폴더를 PC의 지울 일 없는 곳에 둔다. 설치 후에도 폴더를 지우거나 옮기면 안 된다.
2. 웨일 주소창에 `whale://extensions` 를 입력해 확장 프로그램 관리 화면을 연다.
3. 오른쪽 위 **개발자 모드**를 켠다.
4. **압축해제된 확장 프로그램을 로드합니다** 를 눌러 이 `extension` 폴더를 고른다.
5. 웨일 오른쪽 위 퍼즐 모양 아이콘을 눌러 **타오바오 배송 자동 확인** 을 고정해 둔다.
6. 아이콘을 눌러 정산 사이트와 같은 계정으로 로그인한다. 비밀번호는 저장하지 않는다.

## 동작
- 간격마다 한 번 깨어나서, 정산 사이트에서 **아직 안 받은 주문**과 **최근 45일 안에 추가했지만 배송 기록이 없는 주문**만 골라 타오바오에 하나씩(0.45초 간격) 물어본다.
- 웨일의 타오바오 로그인 상태를 그대로 쓴다. 로그인 정보를 다른 곳에 보내지 않는다.
- 백그라운드에서 바로 조회가 막히면, 열려 있는 타오바오 주문 화면(已买到的宝贝)을 통해 조회한다.
- 확인이 실패하면 아이콘에 빨간 `!` 가 뜬다. 아이콘을 누르면 이유가 나온다.
- 아이콘의 **지금 확인** 으로 바로 확인할 수 있고, **설정** 에서 간격(1·3·6·12시간)을 바꿀 수 있다.

## 업데이트
저장소의 `extension` 폴더 파일을 덮어쓴 뒤, `whale://extensions` 에서 이 확장 프로그램의 새로고침 버튼을 누른다.
